# Agent Engineering Projects

个人 Agent 工程项目展示与技术说明索引。

## Projects

### [DSH Case Compiler](./dsh-case-compiler/)

将冗长的 Agent 失败 Session 编译为安全、可重放、可审计的最小回归 Case，用于失败定位与修复验证。

### [FixLoop](./fixloop/)

面向复杂长任务的通用 Agent Harness，并以代码缺陷修复作为参考实现，验证运行时、工具治理、长任务控制和结果验证能力。

### [MemControl](./memcontrol/)

面向 Codex、Cursor 等 Coding Agent 的本地优先记忆控制面，覆盖记忆产生、治理、召回、演化和可验证删除，并提供用户可浏览、可纠错、可清理的管理界面。
